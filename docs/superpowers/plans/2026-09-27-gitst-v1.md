# gitst v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build gitst v1, a read-only, live, mouse-driven git status TUI for small terminal panes.

**Architecture:** A library crate (`gitst`) with a thin binary. A git worker thread shells out to the `git` CLI, parses porcelain output into immutable `Snapshot`s and sends them over a channel to the UI thread. A watcher thread (notify + gitignore filtering + debounce) signals refreshes. The UI thread (ratatui + crossterm) owns all view state, draws a stacked, collapsible dashboard or a full-pane detail view, and resolves mouse clicks through a hit map recorded during each draw.

**Tech Stack:** Rust 2024, ratatui 0.30, crossterm 0.29, notify 8, ignore 0.4, terminal-colorsaurus 1.0, chrono 0.4, clap 4, serde + toml, dirs 6, libc; dev: insta, tempfile.

**Spec:** `docs/superpowers/specs/2026-09-27-gitst-design.md`

## Global Constraints

- Every git invocation: `git --no-optional-locks -C <root> …` with env `GIT_TERMINAL_PROMPT=0`, `GIT_OPTIONAL_LOCKS=0`; stdin null.
- The only repo-mutating command gitst ever runs is `git fetch` (never `--prune` unless `fetch_prune = true`).
- Fetch timeout 60 s (kill on expiry); backoff `min(interval × 2^failures, 60 min)`; manual fetch success resets backoff.
- Colors: base styling uses only the 16 ANSI colors + bold/dim/reverse; truecolor only for tints derived from a detected background.
- Width thresholds: stats/meters need ≥ 36 cols; ages need ≥ 30 cols; borders need ≥ 36 cols and ≥ 14 rows; hint bar needs ≥ 12 rows; below 24 cols render a single `branch ●` line.
- Section order: Changes, Activity, Commits, Branches, Stashes. Minimum expanded section = title + 2 content rows.
- Config file `~/.config/gitst/config.toml`, all keys optional; defaults: `fetch_interval = "5m"`, `fetch_prune = false`, `collapsed = ["branches","stashes"]`, `icons = "none"`, `pulse_seconds = 10`, `max_changes = 1000`, `numstat_max_files = 500`.
- Stale `index.lock` threshold: 10 s. Idle UI wakes at most every 30 s.
- No async runtime. No drag interactions.

## Review Focus

1. Wide/unicode paths (CJK, emoji) in narrow panes: truncation must use display width, never panic, never overflow the row. → Task 9 `truncate_left` tests.
2. Degenerate pane sizes (1×1, 10×3, 0 height): no panic, sensible fallback. → Task 11 render test `tiny_sizes_do_not_panic`.
3. Unborn repo (`git init`, no commits): dashboard renders with `(no commits)`, no error line. → Task 3 integration test `unborn_repo`.
4. Another process holding `index.lock` (agent mid-commit): gitst never blocks and warns only after 10 s. → Task 3 integration test `stale_index_lock_detected`.
5. Remote configured but unreachable: fetch fails fast with a classified reason, never prompts, UI keeps working. → Task 7 integration test `fetch_unreachable_remote_fails_cleanly`.

pub fn parse_numstat(raw: &[u8]) -> Vec<(String /*path (new path for renames)*/, Option<u32>, Option<u32>)>

Records are split on `\x1e` and each is trimmed of leading `\n`; fields on `\x1f`. `%D` refs split on `", "`, `HEAD -> main` becomes `main`, `tag: v1` stays `tag: v1`. Reflog time is the number inside `@{…}` of `%gd`. Stash index is the number inside `stash@{N}`. Numstat binary `-` → `None`; rename record is `a\tb\t\0old\0new\0`.

`CliBackend::new(repo)`; `fn git(&self, args: &[&str]) -> Result<Vec<u8>, GitError>` runs per Global Constraints; non-zero exit → `GitError(first stderr line)`. `discover` runs `git -C path rev-parse --path-format=absolute --show-toplevel --git-dir --git-common-dir`; spawn `NotFound` → `GitMissing`; non-zero exit mentioning "not a git repository" → `NotARepo`. Paths are canonicalized.

Snapshot assembly (`snapshot`):
1. `status --porcelain=v2 -z --branch --show-stash --untracked-files=all` → header + changes. Head: `oid None` + head name → `Unborn`; head None → `Detached(short oid)`.
2. If `changes.len() <= numstat_max_files`: `diff --numstat -z` and `diff --cached --numstat -z`, summed per path; untracked text files < 1 MiB get `added = line count`, `removed = 0`.
3. Truncate to `max_changes` (conflicts sorted first, then path order), set `changes_omitted`.
4. If not unborn: `log -n <commits> --format=LOG_FORMAT HEAD`; if upstream: `rev-list -n 500 @{upstream}..HEAD` → mark `unpushed`.
5. `for-each-ref --sort=-committerdate --format=BRANCH_FORMAT refs/heads`.
6. If `stash > 0`: `stash list --format=STASH_FORMAT`.
7. Reflog: `log -g --date=unix -n 50 --format=REFLOG_FORMAT HEAD` (skip if unborn) plus for each distinct branch upstream starting with a remote name: `log -g --date=unix -n 20 --format=REFLOG_FORMAT refs/remotes/<upstream>` (errors ignored).
8. `describe --tags --long` (errors → None).
9. `op` from files in git_dir: `MERGE_HEAD` → Merge; `rebase-merge/` (`msgnum`,`end`) or `rebase-apply/` (`next`,`last`) → Rebase; `CHERRY_PICK_HEAD`; `REVERT_HEAD`; `BISECT_LOG`.
10. `index_lock_age` from mtime of `git_dir/index.lock`; `last_fetch` from mtime of `common_dir/FETCH_HEAD`; `has_remote` from `git remote` non-empty.

`parse_diff(raw) -> Vec<DiffLine>`: skip `diff --git`, `index `, `--- `, `+++ `, `new file mode`, `deleted file mode`, `similarity`, `rename from/to`; `@@` → Hunk; `+` Add; `-` Del; ` ` Context; `Binary files` and `\ No newline` → Meta. Rendering rules (all widths computed with `fmt::width`):
- **Tiny** (`w < 24`): one line: branch (or `@short`), `↑n↓m` if non-zero, `●` if dirty.
- **Header line 1** (band style, full width): ` <branch>` bold accent (or `@short` / `<branch> (no commits)`), op badge in warn (`MERGING`, `rebase 3/7`, `CHERRY-PICK`, `REVERTING`, `BISECTING`), `↑n` accent / `↓m` warn when non-zero, `●` modified-colour when dirty; right-aligned fetch control `↻ 2m` (spinner frame `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` while running, `↻ –` if never fetched, hidden if no remote) registered as `Action::Fetch`. In a detail view line 1 is `‹ back  <title>` with `‹ back` registered as `Action::Back`.
- **Header line 2** (dim, only when `h >= 10`): upstream name (or `no upstream`), `v0.1.9+4` (or `v0.1.9` when distance 0), `stash N`; joined by ` · `, truncated.
- **Warning lines** (max 2, after header): conflicts `⚠ N conflicts` (err); in-progress op hint `⚠ merge in progress` (warn); `⚠ index.lock held Ns` when age ≥ 10 s; `⚠ fetch failed: <label>`; refresh error `⚠ <msg>`; config warning; `no upstream` is shown in line 2 only.
- **Sections** via `layout::allocate` with `avail = h - header - warnings - hint`. Bordered: rounded `Block` with title `▾ Changes (5)` left and summary right (Changes: `+61 −12`; Commits: `↑2` if unpushed). Compact: title line `▾ Changes (5) ────── +61 −12`. Collapsed: `▸ Commits (12)` single line. Title row registers `Action::Toggle(id)`.
- **Rows** produced by `fn section_rows(id, snap, app, theme, width, density) -> Vec<(Line<'static>, Option<Target>)>`:
  - Changes: `XY path  +a −r ■■■■■ •`; X coloured add (staged), Y coloured modified/del/untracked; conflicts err bold; `+N more` when `changes_omitted`; clean → `✓ clean` in add colour. Pulse `•` in accent while `pulses[path]` is younger than `pulse_secs/2`, dim until `pulse_secs`.
  - Activity: `HH:MM verb text` verb coloured by kind; `merged(&snap.reflog, &app.live, 100)`; empty → `no activity yet` dim.
  - Commits: `short ↑ subject  age` (`↑` only if unpushed, `⑂` prefix marker for merges), tags as `[v0.1]` in accent when width ≥ 50.
  - Branches: `● name  ↑a ↓b` (`●` current, `gone` dim for gone upstreams).
  - Stashes: `stash@{i} message  age`.
- Rows beyond the slot's rows: apply `app.scroll[id]` (clamped), and if rows remain below, the last visible row becomes `+N more` (dim). Each visible row with a target registers `Action::Open`; each section body registers `ScrollTarget::Section`.
- Selection (`app.selected`) row rendered with `theme.select`; hovered row with `theme.hover`.
- **Hint bar** (when `density.hints`): dim ` ? help  f fetch  q quit` (dashboard) or ` ‹ esc back  w wrap  q quit` (detail), each item clickable.
